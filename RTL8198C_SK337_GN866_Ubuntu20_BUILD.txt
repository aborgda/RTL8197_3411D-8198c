RTL8198C SK337 + GN866 AC + RTL8198 KT510 - Ubuntu 20.04 BUILD NOTES
======================================================================

TARGETS
-------
SK337:
  SoC  : RTL8198C
  WiFi : RTL8192ER + RTL8812AR

GN866 AC:
  SoC  : RTL8198C
  WiFi : RTL8192ER + RTL8812BRH / RTL8812AR

KT510:
  SoC  : RTL8198
  WiFi : RTL8192ER + RTL8812AR

IMPORTANT:
RTL8198 and RTL8198C are separate SoC targets. Do not treat KT510 as
an RTL8198C board just because the WiFi chipset combination is similar.

SOURCE
------
git@github.com:aborgda/RTL8197_3411D-8198c.git

1. INSTALL BUILD TOOLS
----------------------
sudo dpkg --add-architecture i386
sudo apt update
sudo apt install -y git build-essential gcc g++ make bc bison flex \
  libncurses-dev libssl-dev zlib1g-dev libelf-dev libc6-dev-i386 \
  lib32gcc1 lib32stdc++6 lib32z1 python3 python3-distutils \
  rsync unzip wget file cpio gettext pkg-config gawk sed grep \
  autoconf automake libtool texinfo

If lib32gcc1 is unavailable:
  sudo apt install gcc-multilib g++-multilib

2. CLONE
--------
cd ~
git clone git@github.com:aborgda/RTL8197_3411D-8198c.git
cd RTL8197_3411D-8198c

3. CHECK SDK
------------
find . -maxdepth 3 -type f | grep -Ei '8198|8198c|8812|8192|board|config|image|makefile' | head -200
find . -type f -name Makefile | head -100
grep -RniE 'RTL8198C|RTL8198' . 2>/dev/null | head -200
grep -RniE 'RTL8192ER|RTL8192E|RTL8812AR|RTL8812BRH' . 2>/dev/null | head -200

4. KT510 BOARD REQUIREMENTS
---------------------------
KT510 must have a REAL RTL8198 board definition.

Required:
  - RTL8198 CPU/platform support
  - KT510 board profile
  - RTL8192ER driver
  - RTL8812AR driver
  - correct GPIO
  - correct flash size/layout
  - Ethernet/PHY configuration
  - PCIe/WiFi configuration
  - LED/button definitions
  - image Makefile
  - correct Realtek firmware/header format
  - bootloader-compatible checksum

Do not create KT510 by changing only:
  CONFIG_TARGET_realtek_rtl8198c

That would incorrectly build an RTL8198C target.

5. FIND RTL8198 SUPPORT
-----------------------
grep -RniE '8198[^C]|RTL8198[^C]' . 2>/dev/null | head -200
find . -type f | grep -Ei '8198[^c].*(board|config|mach|image|make)|board.*8198' | head -200

If no RTL8198 platform/board code exists, the SDK still needs the
RTL8198 target port before KT510 can build.

6. KT510 GPIO / FLASH
---------------------
Use KT510 original dump/board data for:
  GPIO
  LEDs
  buttons
  Ethernet PHY
  flash size/layout
  WiFi calibration
  image header

Do NOT copy SK337/GN866 GPIO or flash layout into KT510 unless the
hardware dumps prove they are identical.

7. WIFI CHECK
-------------
find . -type f | grep -Ei '8192er|8192e|8812ar' | head -200
grep -RniE '8192ER|8812AR' . 2>/dev/null | head -200

8. BUILD ORDER
--------------
Recommended order:

  A. Build existing RTL8198C target first.
  B. Confirm SK337/GN866 image generation.
  C. Add/verify RTL8198 platform.
  D. Add KT510 board profile.
  E. Add RTL8192ER + RTL8812AR.
  F. Add KT510 GPIO/flash/image definitions.
  G. Build KT510 with make -j1 V=s.

First build:
  make -j1 V=s

After successful testing:
  make -j$(nproc) V=s

9. OPENWRT TARGET CHECK
-----------------------
If using a separate OpenWrt tree:

cd ~/openwrt-realtek
find target/linux -maxdepth 4 -type f | grep -Ei '8198|realtek'
grep -RniE 'RTL8198|8198C|KT510|SK337|GN866' target 2>/dev/null | head -300

Do not use a CONFIG_TARGET symbol unless the matching target files,
image Makefile and board definitions exist.

10. TARGET MAPPING
------------------
SK337:
  RTL8198C + RTL8192ER + RTL8812AR

GN866_AC:
  RTL8198C + RTL8192ER + RTL8812BRH/RTL8812AR

KT510:
  RTL8198 + RTL8192ER + RTL8812AR

11. IMAGE CHECK
---------------
find bin -type f | grep -Ei '8198|kt510|sk337|gn866|sysupgrade|factory|fw\.bin|linux\.bin|root\.bin'

For verbose logging:
  make -j1 V=s 2>&1 | tee build.log

12. HOST CHECK ERRORS
---------------------
If these fail:
  argp.h
  fts.h
  obstack.h
  libintl.h

Run:
  sudo apt update
  sudo apt install -y libargp-dev gettext

Then:
  make -j1 V=s

Do not use FORCE=1 as the first solution.

13. MIPS TOOLCHAIN
------------------
Do not replace the Realtek MIPS cross compiler with Ubuntu host gcc.

Find it:
  find . -type f \( -name '*mips*gcc' -o -name 'mips*cc' \) 2>/dev/null

Check:
  file /PATH/TO/COMPILER

-------------------------

15. IMPORTANT
-------------
RTL8198C targets:
  SK337
  GN866_AC

RTL8198 target:
  KT510

Keep these target families separate in Kconfig, board code, image
Makefiles, GPIO, flash definitions and firmware headers.
